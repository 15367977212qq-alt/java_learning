1.
继承解决什么问题？

继承负责解决多个实例重复实现一个同类方法，实现了代码复用性

2.

为什么：
Animal animal=new Dog();
可以成立？

Dog 继承了 Animal，Dog 是一种 Animal，
因此 Animal 类型的引用可以指向 Dog 对象，这称为向上转型，也是多态的基础。

3.

接口和抽象类有什么区别？

接口中的抽象方法必须全部实现，抽象类中的抽象方法不一定需要全部实现

普通实现类必须实现接口中尚未实现的抽象方法。
普通子类也必须实现抽象父类中尚未实现的抽象方法。
如果实现类或子类本身也是抽象类，则可以暂时不实现。
一个类只能继承一个父类，但可以实现多个接口。
抽象类可以有实例字段、构造方法和普通方法；接口主要定义能力规范

4.

为什么企业代码喜欢：
接口 + 实现类

接口用来声明接口类型，同一管理接口，实现类用来具体编写具体的实现方法，这样管理
后续方便维护各个接口的实现内容，接口还可以跟多态结合使用
5.

equals和==有什么区别？

比较方式   基本数据类型  引用数据类型（对象）
== 比较数值是否相等比较内存地址（是否指向堆中的同一个对象）
equals()不能使用（编译报错）默认比较内存地址（同 ==）；
但像 String、Integer 等类重写了该方法后，会比较对象内容。
